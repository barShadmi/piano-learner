# Skills in this repo

Claude Code loads every skill in `.claude/skills/` when it works in this folder. They were carried over from MindLane; licences are in `.claude/skills/_licenses/`. The `claude-api` skill is built into Claude Code and is used for the scanner.

| Job | Skills |
| --- | --- |
| Start of every session | `using-superpowers` |
| Build the next task (lead runs it) | `build-task` |
| End of a phase (lead runs it) | `phase-review` |
| Shaping a feature before code | `brainstorming`, `writing-plans`, `user-journey`, `persona-builder` |
| Building | `executing-plans`, `subagent-driven-development`, `dispatching-parallel-agents`, `test-driven-development`, `frontend-design`, `web-design-engineer` |
| Bugs | `systematic-debugging` |
| Before calling anything done | `verification-before-completion`, `iterate-until-verified`, `audit-verify-explain-grade-5` |
| Code review | `requesting-code-review`, `receiving-code-review` |
| Finishing a branch | `finishing-a-development-branch`, `using-git-worktrees` |
| Design system | `design-systems`, `design-critique` |
| Motion (falling notes, hands) | `emil-design-eng`, `animate`, `review-animations`, `animation-performance` |
| Interaction | `interaction-design`, `break-ui` |
| Words on screen | `ux-writing`, `ux-copy` |
| Accessibility | `accessibility-audit`, `accessibility-review` |
| Speed and latency | `performance-profiling`, `animation-performance` |
| Testing with a beginner's eyes | `ux-validate`, `persona-builder`, `user-journey` |
| Scanning with Claude | `claude-api` (built in) |

Left out from MindLane on purpose: sales page, SEO, marketing, email, Canva, Figma and payment skills. This app is just for Bar.
